# 3D-Motion-Tracking-Physics
Physics project analyzing projectile motion using phone-camera motion tracking and trajectory analysis.
## Project Overview

This project analyzes projectile motion using video-based motion tracking. A ball was recorded using a phone camera, and the motion was analyzed to study trajectory behavior, gravitational acceleration, and real-world projectile motion.

## Objectives

- Analyze projectile motion using experimental video data
- Track motion frame-by-frame
- Compare observed motion with theoretical physics
- Estimate gravitational acceleration from trajectory data
- 
## Methodology

1. A ball was thrown and recorded using a phone camera.
2. Motion tracking software (Kinovea) was used to extract trajectory points.
3. Position-time data was analyzed.
4. Graphs were generated to study projectile motion behavior.
5. Experimental results were compared with theoretical expectations.

## Key Results
- The projectile followed a parabolic trajectory consistent with theoretical predictions.
- Experimental motion closely matched the theoretical projectile model.
- Gravitational acceleration was estimated to be approximately 9.8 m/s².
- Small deviations were observed due to air resistance and measurement inaccuracies.
